## 🚀 安装后的使用方法

### 一键启动（推荐）

```bash
# 双击运行项目根目录的"一键启动.bat"
# 脚本会自动检测环境类型（Conda 或 UV）并启动
# 浏览器会在服务器就绪后自动打开
```

### 手动启动

**Conda 环境**
```bash
conda activate IndexTTS
python webui.py

# 启用优化（降低显存占用）
python webui.py --use_fp16 --use_deepspeed
```

**UV 环境**
```bash
# 方式1：激活环境后运行
.venv\Scripts\activate
python webui.py

# 方式2：直接用 UV 运行
uv run python webui.py

# 启用优化（降低显存占用）
python webui.py --use_fp16 --use_deepspeed
```

### 命令行参数说明

| 参数 | 说明 | 推荐场景 |
|------|------|---------|
| `--use_fp16` | 使用半精度浮点数，降低显存占用 50% | 显存不足时使用 |
| `--use_deepspeed` | 启用 DeepSpeed 加速 | 可能提升性能（需测试）|
| `--use_cuda_kernel` | 使用 CUDA 自定义核心 | 追求极致性能 |
| `--use_torch_compile` | 使用 Torch 编译优化 | PyTorch 2.0+ |

## 🔧 系统要求

### 最低配置（CPU 模式）

- **CPU**：Intel i5 / AMD Ryzen 5 以上
- **内存**：8GB RAM
- **磁盘**：20GB 可用空间
- **网络**：稳定的互联网连接

### 推荐配置（GPU 模式）

- **CPU**：Intel i7 / AMD Ryzen 7 以上
- **GPU**：NVIDIA RTX 3060 (8GB 显存) 或更高
- **内存**：16GB RAM
- **磁盘**：30GB 可用空间
- **CUDA**：CUDA Toolkit 12.1+

### 最佳配置（极致体验）

- **CPU**：Intel i9 / AMD Ryzen 9 以上
- **GPU**：NVIDIA RTX 4090 (24GB 显存)
- **内存**：32GB RAM
- **磁盘**：50GB SSD
- **CUDA**：CUDA Toolkit 12.4+

## 📥 模型下载

### 自动下载（推荐）

部署脚本会自动下载，策略如下：
1. **优先使用 ModelScope**（国内用户速度快）
2. 失败后**自动切换 HuggingFace**
3. 两者都失败时提示手动下载

### 手动下载（可选）

如果自动下载失败：

**方式1 - ModelScope（国内推荐）**
```bash
modelscope download --model IndexTeam/IndexTTS-2 --local_dir checkpoints
```

**方式2 - HuggingFace**
```bash
hf download IndexTeam/IndexTTS-2 --local-dir=checkpoints
```

**方式3 - 网页下载**
- ModelScope：https://modelscope.cn/models/IndexTeam/IndexTTS-2
- HuggingFace：https://huggingface.co/IndexTeam/IndexTTS-2

下载后解压到项目根目录的 `checkpoints` 文件夹。

## ❓ 常见问题

### Q1: 提示"环境检测失败"

**原因：** 选择的环境类型未安装

**解决方案：**

**选择 Conda 但未安装：**
1. 下载并安装 Miniconda：https://docs.conda.io/en/latest/miniconda.html
2. 安装完成后重新运行脚本
3. 或返回选择界面，选择"Python + UV"

**选择 Python 但未安装：**
1. 下载并安装 Python 3.10+：https://www.python.org/downloads/
2. 安装完成后重新运行脚本
3. 或返回选择界面，选择"Conda 虚拟环境"

**智能设计：**
- 脚本检测失败后会返回选择界面，不会直接退出
- 可以安装环境后立即重新运行

---

### Q2: 想用 GPU 但自动选择了 CPU 模式

**原因：** 未检测到 NVIDIA 显卡驱动

**解决方案：**

**安装 NVIDIA 驱动：**
1. 下载并安装 NVIDIA 显卡驱动
   - GeForce 显卡：https://www.nvidia.com/Download/index.aspx
   - 或使用 GeForce Experience 自动更新

2. 下载并安装 CUDA Toolkit 12.1+
   - 下载地址：https://developer.nvidia.com/cuda-toolkit

3. 重启电脑

4. **重新运行脚本**，系统会自动检测到 CUDA 并使用 GPU 模式

**验证 CUDA：**
```bash
# 检查驱动
nvidia-smi

# 应该显示显卡信息和 CUDA 版本
```

**智能设计：**
- 每次运行脚本都会重新检测 CUDA
- 安装驱动后无需修改配置，直接重新运行即可

---

### Q3: 模型下载失败

**原因：** 网络问题或下载源不可用

**解决方案：**

**快速修复**
```bash
# 国内用户：设置 HuggingFace 镜像
set HF_ENDPOINT=https://hf-mirror.com

# 重新下载
modelscope download --model IndexTeam/IndexTTS-2 --local_dir checkpoints
```

**手动下载步骤**
1. 访问下载页面（见"模型下载"章节）
2. 下载所有文件
3. 解压到 `checkpoints` 文件夹
4. 确保 `checkpoints\config.yaml` 存在

---

### Q4: 启动时提示缺少依赖

**原因：** 依赖安装不完整

**解决方案：**

**Conda 用户**
```bash
conda activate IndexTTS
pip install -r requirements.txt
```

**UV 用户**
```bash
uv sync --all-extras
```

---

### Q5: 显存不足 (Out of Memory)

**原因：** 显卡显存不够

**解决方案：**

**方案1：使用 FP16 模式**
```bash
python webui.py --use_fp16
```
降低 50% 显存占用，质量几乎无损。

**方案2：优化系统**
- 关闭其他占用显存的程序（浏览器、游戏）
- 减少生成文本长度
- 降低批处理大小

**方案3：升级硬件**
- 推荐 8GB+ 显存的显卡（如 RTX 3060）

---

### Q6: CPU 模式运行很慢

**原因：** CPU 计算能力远低于 GPU

**性能对比：**
- **GPU (CUDA)**：1-3 秒生成 10 秒语音
- **CPU**：10-60 秒生成 10 秒语音（慢 10-50 倍）

**解决方案：**
1. **耐心等待**：首次推理可能需要 1-5 分钟
2. **升级硬件**：购买 NVIDIA 显卡
3. **云端运行**：使用 Google Colab 等云端 GPU 服务

---

### Q7: 首次运行很慢

**原因：** 首次运行会自动下载小模型

**说明：**
首次运行会下载以下模型（约 500MB）：
- campplus（说话人识别）
- semantic_codec（语义编码器）

**解决方案：**
- 耐心等待（仅首次需要）
- 设置镜像：`set HF_ENDPOINT=https://hf-mirror.com`

---

### Q8: 加载音频文件失败（m4a 格式）

**原因：** 缺少 ffmpeg

**解决方案：**

**方案1：通过 Conda 安装**
```bash
conda install -c conda-forge ffmpeg -y
```

**方案2：手动安装**
1. 下载 ffmpeg：https://ffmpeg.org/download.html
2. 解压到任意目录
3. 添加到系统 PATH 环境变量

## 💡 使用技巧

### 1. 选择高质量参考音频

**推荐参数：**
- **时长**：3-10 秒
- **音质**：清晰无杂音，采样率 ≥16kHz
- **内容**：纯人声，无背景音乐
- **格式**：WAV / MP3 / M4A

**示例音频位置：**
```
examples/
├── voice_01.wav  # 男声示例
├── voice_07.wav  # 女声示例
└── emo_sad.wav   # 情感示例
```

### 2. 情感控制技巧

**方式1：情感音频参考**
```python
tts.infer(
    spk_audio_prompt='voice.wav',      # 音色参考
    emo_audio_prompt='emo_sad.wav',   # 情感参考
    text='你的文本'
)
```

**方式2：情感向量控制**
```python
# 8种情感：[开心, 生气, 悲伤, 恐惧, 厌恶, 忧郁, 惊讶, 平静]
emo_vector = [0, 0, 0.8, 0, 0, 0, 0, 0.2]  # 80%悲伤 + 20%平静

tts.infer(
    spk_audio_prompt='voice.wav',
    emo_vector=emo_vector,
    text='你的文本'
)
```

**方式3：文本情感描述**
```python
tts.infer(
    spk_audio_prompt='voice.wav',
    use_emo_text=True,
    emo_text='害怕恐惧的语气',
    text='你的文本'
)
```

### 3. 拼音控制发音

**用途：** 精确控制多音字发音

**示例：**
```python
text = "之前你做DE5很好，所以这一次也DEI3做DE2很好才XING2"
# DE5 → de（轻声）
# DEI3 → děi（三声）
# DE2 → dé（二声）
# XING2 → xíng（二声）
```

**拼音表：** 查看 `checkpoints/pinyin.vocab`

### 4. 性能优化建议

**显存不足（<8GB）**
```bash
python webui.py --use_fp16
```

**追求速度**
```bash
python webui.py --use_fp16 --use_deepspeed --use_cuda_kernel
```

**批量生成**
- 一次生成多个音频更高效
- 建议使用 Python API 而非 WebUI

## 📊 Conda vs UV 对比

| 特性 | Conda 环境 | UV 环境 |
|------|-----------|---------|
| **安装速度** | 中等 | 最快（比 pip 快 115 倍）|
| **稳定性** | 中 | 最高 |
| **依赖管理** | 较宽松 | 精准（锁定版本）|
| **适合人群** | 新手 | 高级用户 |
| **官方推荐** | ❌ | ✅ |
| **环境隔离** | ✅ 强 | ✅ 强 |
| **磁盘占用** | 较大 | 较小 |

**推荐选择：**
- 新手用户 → Conda（简单易用）
- 高级用户 → UV（性能最佳）
