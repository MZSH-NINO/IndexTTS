# 一键部署工具

本文件夹包含 IndexTTS-2 的自动化部署和启动脚本。

## 📁 文件说明

### 部署脚本
- **一键部署.bat** - 交互式部署向导（v2.0）
  - 用户选择环境类型（Conda / Python+UV）
  - 自动检测对应环境是否存在
  - 自动检测 CUDA 并选择最佳配置
  - 自动完成环境搭建和模型下载

### 文档
- **部署使用说明.md** - 完整的部署和使用指南

---

## 🚀 快速使用

### 第一步：部署
1. 双击运行 `一键部署.bat`
2. 选择环境类型（Conda / Python+UV）
3. 系统自动检测并配置（包括 CUDA）
4. 确认并等待安装完成

### 第二步：启动
部署完成后，返回项目根目录，双击运行 `一键启动.bat`
- 脚本会自动检测您部署的环境类型（Conda 或 UV）
- 自动激活对应环境并启动 WebUI
- 浏览器会在服务器启动后自动打开

---

## 💡 智能特性

- ✅ **实时检测**：每次运行都重新检测环境，安装缺失环境后可立即重试
- ✅ **自动配置**：CUDA 检测全自动，无需手动选择 GPU/CPU
- ✅ **友好提示**：检测失败不会退出，会提示安装地址并返回选择
- ✅ **灵活切换**：可以随时返回上一步重新选择
